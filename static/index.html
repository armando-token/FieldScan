PLANNED EXTENSION · ZERO WRITES IN PILOT

FieldScan already guides inspection and reads our TZONE sensors over Modbus. Calibration and Verified Adjustment is a planned extension. It will compare a device against a reference and, on documented compatible models, apply and verify an adjustment.

Current Bench Hardware Scope (TZONE TZ THT-02 / THT-03R)

Published TZONE manuals document communication baud rate (0x0005) as the only writable parameter and publish no temperature or relative humidity offset registers. FieldScan keeps TZONE units strictly in read-only Function 0x03 mode.
